How to connect an iPhone / iPad / Mac
  1. iPhone: Settings → Mail → Accounts → Add Account → Other → Add Mail Account
  2. Enter any name and email (e.g. you@arozos), then choose IMAP and fill both incoming and outgoing servers with the values above
  3. If a certificate warning appears, tap Continue to trust the self-signed certificate — this is expected for a local server
  4. In the account’s Advanced settings confirm SSL is On and the port matches
  5. Switch Notes ON (Mail can stay off) for the account

Mac: System Settings → Internet Accounts → Add Other Account → Mail Account, then enable only Notes for it. Accept the certificate prompt when it appears.
