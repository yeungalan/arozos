Apple Notes Sync

Sync notes between arozos and Apple Notes via iCloud IMAP

iCloud Credentials
Generate an app-specific password at appleid.apple.com → Sign In & Security → App-Specific Passwords. Required when two-factor authentication is enabled.
Server Settings (Advanced)
Usually "Notes". Some iCloud accounts use "INBOX.Notes". Use an IMAP client to confirm the exact folder name if sync fails.
