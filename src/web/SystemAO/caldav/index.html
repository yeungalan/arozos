CalDAV Notes Sync
Sync ArozOS Notes with CalDAV clients (e.g. iPhone Reminders)


When enabled, notes are accessible as VTODO items via the CalDAV protocol on the same port as ArozOS.

How to Connect

Your Notes are exposed as VTODO calendar items. On iOS/macOS, add a CalDAV account (Settings → Calendar → Accounts → Add Account → Other → Add CalDAV Account).

Important: When adding the account in macOS/iOS, you must enter the full URL below (including your username) as the server address — not just the hostname. Entering only the hostname causes the account to appear connected but never sync, because credentials are not stored for background sync daemons.

Get your Auto-Login Token

The CalDAV password is your auto-login token. To get one:

  1. Open System Setting → Security → My Account
  2. Scroll to Auto Login Token and click New Token
  3. Copy the generated token and use it as the CalDAV password
Apple Reminders (iOS/macOS): After adding the CalDAV account you will see a list named Notes appear in the Reminders app. Each reminder corresponds to one ArozOS note — the reminder title = first line of the note, notes field = full body. Changes sync bidirectionally: edits made in ArozOS Notes or in Reminders propagate to both sides.
Apple Notes app does not support CalDAV — use Reminders instead. The CalDAV protocol maps ArozOS notes to Reminders items (VTODO).
