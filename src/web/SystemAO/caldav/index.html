CalDAV Notes Sync
Sync ArozOS Notes with CalDAV clients (e.g. iPhone Reminders)


When enabled, notes are accessible as VTODO items via the CalDAV protocol on the same port as ArozOS.

How to Connect

Your Notes are exposed as VTODO calendar items. On iOS/macOS, add a CalDAV account (Settings → Calendar → Accounts → Add Account → Other → Add CalDAV Account).

Get your Auto-Login Token

The CalDAV password is your auto-login token. To get one:

  1. Open System Setting → Security → My Account
  2. Scroll to Auto Login Token and click New Token
  3. Copy the generated token and use it as the CalDAV password
Apple Reminders (iOS/macOS): After adding the CalDAV account, open the Reminders app and you will see a list named Notes. Each reminder corresponds to one ArozOS note — the title maps to the reminder title and the body maps to its notes field.
