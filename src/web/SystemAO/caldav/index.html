How to Connect (iOS / macOS)

  1. Go to Settings → Calendar → Accounts → Add Account → Other → Add CalDAV Account
  2. Set Server to: loading...
  3. Set Username to your ArozOS username
  4. Set Password to your ArozOS Auto-Login Token (see below)
  5. Tap Next — iOS will discover the Notes calendar automatically
Your notes will appear in the Reminders app on iOS/macOS after account setup. Changes on either side sync bidirectionally.
