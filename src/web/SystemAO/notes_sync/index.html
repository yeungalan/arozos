Apple Notes Sync
Bidirectional sync between arozos Notes and iPhone Notes via IMAP

Server Settings

Standard IMAP is port 143 (needs root). IMAPS (TLS) is 993 (needs root). Default 1143 avoids needing root.

Your IMAP Access Token

Use this token as the password when adding the IMAP account on your iPhone. Your username is shown next to each token and stays the same as your arozos login.

iPhone Setup Instructions

⚠ No TLS certificate detected. The server is running in plain-IMAP mode. You must disable SSL in iPhone's Advanced settings after adding the account (step 6 below).
✓ TLS is enabled. You can keep SSL turned on in iPhone settings.
  1. Open Settings on your iPhone.
  2. Go to Mail → Accounts → Add Account → Other → Add Mail Account.
  3. Fill in the basic details:
    NameArozOS Notes
    Emailusername@arozos
    Passwordpaste your token above
    DescriptionArozOS Notes
  4. Tap Next. iPhone will try to auto-discover settings and fail — that's expected. It will then show the manual server form.
  5. Fill in the Incoming Mail Server (IMAP) details:
    Host Nameyour-server-ip-or-hostname
    Port1143
    Usernameusername
    Passwordsame token
  6. For Outgoing Mail Server (SMTP), set the hostname to the same value but you can leave the username/password blank — Notes sync does not need outgoing mail.
  7. Disable SSL (required for plain IMAP): Tap Save even if it shows a warning. Then go to Settings → Mail → Accounts → ArozOS Notes → Account → (tap the account name again) → Advanced and set Use SSL → Off and Authentication → Password.
  8. After saving, you'll be asked which services to enable. Turn Mail off and Notes on, then tap Save.
  9. Open the Notes app — your arozos notes will appear under the ArozOS Notes account.
