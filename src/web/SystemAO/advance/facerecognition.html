Feature Switch
When enabled, the Photo app scans each user's indexed photos for faces in the background and groups similar faces into "People". Everything runs locally on this server using a built-in lightweight model — no photo, face or biometric data ever leaves this host.
Enable face recognition
Disabled — the Photo app shows no face features.
This is an optional feature and is turned off by default. Scanning only happens for users who open the Photo app while the feature is on. Each user only ever sees faces found in photos they can access themselves.

Privacy & Data
Detected faces (position, a small thumbnail and a numeric texture signature) are stored per user in the system database. Users can clear their own data from the Photo app at any time; the button below wipes the stored face data of every user on this server. Photos themselves are never modified. Grouping uses a classic, lightweight algorithm — expect it to be helpful rather than perfect, especially compared to cloud services.
Supported formats: JPEG, PNG and WebP. RAW photos (ARW / CR2 / DNG / NEF / RAF / ORF) are skipped — their embedded previews are not scanned. Maximum image size per scan: 25 MB.
