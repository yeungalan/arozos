Notes Sync
Sync the Notes app with Apple Notes over IMAP
Sync Server Off
Apple Notes has no public sync API, but it natively supports adding a plain IMAP account and treats a "Notes" folder as a Notes account — the same way it syncs with Gmail or Fastmail. Turning this on starts a small IMAP server so users can add ArozOS as that account. No Apple ID or iCloud credentials are ever involved; each user gets their own per-device sign-in code from inside the Notes app.
